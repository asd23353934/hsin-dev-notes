## 待補

此資料夾目前為**結構佔位**。Unity / C# 的版本與套件**待實際專案開工時，依 [_global/rules.md](../_global/rules.md) §7 驗證後填入**（Unity LTS 版本、URP / HDRP、Input System、DOTween、測試框架等）。

慣例（C# coding style、ScriptableObject 用法、場景 / prefab 組織、Addressables）與踩坑，請在實際遇到時分別建 `conventions.md` / `errors.md`，套用 [CLAUDE.md](../CLAUDE.md) 的模板。

> 註：`godot/stack.md` 寫「不用 .NET / C#」是 **Godot 端**的決定；Unity 端走 C# 是另一條線，兩者並存（同款遊戲 `dice-fate-survivor` 有 Godot 與 Unity 兩版）。
